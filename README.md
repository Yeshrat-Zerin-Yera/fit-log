# FitLog

FitLog is a modern workout library and fitness planner built with Next.js. Users can browse workouts, view workout details, add exercises to today's plan, save workouts for later, and track completed exercises.

## Live Project

https://fit-log-three-bice.vercel.app/

## Technologies Used

- Next.js
- TypeScript
- Tailwind CSS
- daisyUI
- Lucide React
- Next.js App Router
- REST API
- LocalStorage

## Features

- Browse a workout library with workout cards and detailed information.
- View complete workout details including equipment, difficulty, sets, reps, duration, calories, rating, and instructions.
- Add workouts to today's plan with a maximum of 5 exercises.
- Save workouts for later.
- View today's workout plan and saved workouts in separate tabs.
- Mark workouts as completed and remove workouts from the plan.
- Workout plan and saved workouts persist using LocalStorage.
- Sort workouts by duration, calories, or rating.
- Responsive design for mobile, tablet, and desktop devices.
- Toast notifications for workout actions.
- Custom loading and 404 pages.

## API

FitLog uses the FitLog workout API:

`https://api.api-store.workers.dev/api/fitlog`
